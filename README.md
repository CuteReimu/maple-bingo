# 名侦探甘迪助手

## 游戏规则

名侦探甘迪是《冒险岛Online》推出的一个小游戏。系统会从 1-9 九个数字中随机选择三个不同的数字，按某个顺序排列作为答案。

玩家每轮按顺序猜三个不同的数字，系统会给出两种反馈：
- **○**：数字正确且位置正确的个数
- **△**：数字正确但位置错误的个数

目标是用尽可能少的轮次猜出正确答案。

## 解法：最大化信息熵策略

本项目使用**最大化信息熵**策略来给出每轮的最优猜测建议。

### 核心思路

信息熵衡量一次猜测能消除多少不确定性。对于每种可能的猜测，计算其信息熵：

$$
H = -\sum_{i} p_i \log_2 p_i
$$

其中 $p_i$ 是每种反馈结果出现的概率。每轮选择信息熵最大的猜测，即可最高效地缩小候选范围。

### 额外优化

当反馈为 3○（直接猜中）时，给予额外信息量奖励（经验值 +10），优先鼓励有机会直接猜中的猜测：

$$
H_i = p \cdot \log_2\left(\frac{1}{p} + 10\right) \quad \text{（仅当反馈为 3○ 时）}
$$

该策略可保证在 6 次以内猜出答案，数学期望约为 4.7 次。

## 技术实现

- **算法**：JavaScript 实现最大化信息熵策略
- **前端**：[Vue 3](https://vuejs.org/) + [Element Plus](https://element-plus.org/)，CDN 方式引入，无需构建工具
- **候选空间**：1-9 中三个不同数字的全排列，共 504 种

## 使用方式

直接用浏览器打开 `index.html` 即可（需要网络连接以加载 CDN 资源）。

每轮按照助手的建议进行猜测，将系统给出的 ○ 和 △ 数量填入输入框，点击"确认反馈"，助手将自动给出下一轮最优猜测。
